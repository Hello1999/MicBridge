# MicBridge 界面与交互说明

## 2026-09-22：面向系统麦克风的操作流程

页面将“现在是什么状态”和“下一步做什么”放在前面。麦克风控制作用于 Android 系统，不要求用户理解或填写目标应用包名，也不把 ChatGPT 的权限当作系统开关状态。

| 页面 | 用户任务 |
| --- | --- |
| 麦克风 | 查看系统状态；启动屏蔽、恢复麦克风或立即屏蔽；处理当前阻碍恢复的下一项条件 |
| 连接 | 按需配置 iPhone 遥控；复制地址、访问密钥与请求头值；高级连接内调整端口或重置密钥 |
| 设置 | 管理后台运行、查看使用前准备、进入设备验证与高级维护 |
| 设备验证 | 按“准备测试 / 确认可以收音 / 确认已经屏蔽 / 完成设备验证”确认此设备的实际效果 |
| 高级维护 | 切换系统控制方案、设置临时验证时限、管理 Root 保护并查看诊断 |

首页停止状态显示“开启麦克风屏蔽”；已屏蔽且验证、保护条件成立时显示“恢复麦克风”。开放、未知或操作中保持“立即屏蔽”可达。未满足验证或权限时给出具体下一步，不用一个失败按钮代替说明。本地启动、恢复和验证不要求 LAN 授权；远程授权入口位于连接页。精确闹钟只用于临时设备验证，已验证设备的日常持续恢复不被该权限阻挡。

本地恢复使用服务 `ACTION_TOGGLE`，共享 HTTP toggle 的串行状态机和 OPEN 安全检查，不通过局域网请求绕一圈。成功开放持续到下一次屏蔽或安全边界触发；临时验证仍使用有限租约。UI 不维护一份猜测的开关状态，唯一状态源仍是 `ServiceRuntime.snapshot`。从测试应用或系统设置返回时不再重复发出 `ACTION_START`，避免每次回到页面都重新触发启动屏蔽；权限、网络和保护变化仍由服务监控处理。返回页面及权限监控会独立刷新电池准备状态；即使未授予 LAN 权限，完成系统设置后也能继续本地验证，刷新不会改写麦克风读回或校准租约。

设备验证可使用任意有录音权限、能持续收音的应用。先实际确认 OPEN 可收音，再进入仅 Root 门屏蔽并确认无声，最终完整屏蔽后保存。没有活动录音流或没有录音权限时的“无声”不能算通过。步骤、Root 保护、系统双读回和最终安全边界仍由服务检查，界面简化不取消这些检查。首次保存需要本轮同一会话的实际收音、屏蔽和锁屏/熄屏证据，不再要求一个没有对应重复流程的“至少 20 次”勾选；重复切换属于发布真机验收。

目标包名输入已移除。控制方案和 Root 维护仍保留在高级页；技术状态与原始错误集中在诊断，普通页面使用系统麦克风、设备验证、访问密钥等可理解的说明。校准退出仍先请求完整屏蔽，只有新鲜读回与租约清理完成才离开。

此次系统控制语义与校准身份一并更新，旧校准会失效，需要在目标设备重新验证。当前检查结果与待验边界见 [系统麦克风审查](SYSTEM_MIC_REVIEW_ZH.md)。

## 历史记录：2026-09-12 Compose 改版

本轮将原来的单页设置界面改为清晰的原生工具界面，采用蓝灰配色、独立深色主题、统一字阶和线性图标。强调麦克风的真实状态及当前操作，减少技术说明在首页的占用。

### 页面与交互

- **控制**：突出麦克风访问状态，分别显示控制读回与声学校准。立即屏蔽保持可达，切换中也不会移除这一操作。连接与校准各有独立入口。
- **连接**：显示所有可用请求地址、受遮罩保护的令牌和端口设置。复制操作在当前页面底部反馈；离开页面后不保留令牌显示状态。更换令牌前明确提示旧快捷指令将失效。
- **设置**：以分组列表呈现后台运行、权限、Root 开机保护与维护。开关整行可点击；停止服务等按钮使用完整宽度，适配窄屏与大字体。
- **校准**：以四个步骤引导临时开放、恢复收音、Root 隔离屏蔽与最终确认。阶段由服务端的真实校准会话发布，按钮同时检查读回、有效租约和执行状态。人工确认不会跨步骤或旋转恢复为已完成。
- **诊断 / 高级控制**：保留完整错误、控制器探测、最近操作和维护入口；日志时间使用设备本地时区。高级设置保持原有锁定条件。

包名、端口和开放时限的输入草稿独立保存，其他设置刷新不会再清空未提交的输入。导航返回时保留页面滚动位置。一般反馈使用 Snackbar，字段错误在字段旁显示。

校准页存在正在执行的步骤或未结束的本轮证据时，返回或切换页面会先请求完整屏蔽。只有服务发布新的屏蔽读回、租约清理及校准会话重置后才离开；未确认时留在校准页，允许重试。

### 实现位置

- `app/src/main/java/com/jack/micbridge/MainActivity.kt`：启动入口、系统栏与原有返回前台安全边界。
- `app/src/main/java/com/jack/micbridge/ui/`：主题、图标、公共组件、页面、状态呈现与 UI 事件。
- `CalibrationSession` / `ServiceRuntime`：新增只读阶段和执行状态发布，不参与控制授权；显示观察器的失败不会改变校准操作结果。
- `app/src/main/res/values-night/themes.xml`：深色启动背景及系统栏。

未引入新的 UI 依赖。现有控制器、HTTP 协议、Root 门控、音效和校准持久化规则继续生效。
